# 使用指南

## 第一次打开

软件启动后显示 Dock 和顶部 HUD。通过 HUD 打开工作台；右键 HUD 可退出整个程序。工作台右上角的关闭按钮只隐藏工作台，不代表退出程序。

点击工作台左上角头像，修改图片或显示名字。名字留空时首页显示“我的工作台”。设置 → 外观可切换主题；原有个人图片保存在本机，不会上传到项目仓库。

## 桌面与启动

设置 → 桌面与启动可登记“登录 Windows 时启动”，在 Windows 返回的当前用户启动文件夹中创建 `GleamDesk.lnk`，不需要管理员权限。快捷方式直接指向当前 EXE，工作目录为程序所在目录，不使用终端或脚本。开启时移除旧版同名 Run 启动项，避免重复启动；失败时恢复原项。移动便携版后需重新设置；Windows 自己的“启动应用”若禁用此项，需要在那里重新开启。升级保留入口；本版安装器卸载时仅清理指向该安装位置的启动快捷方式，保留指向另一份便携版的快捷方式。删除便携版前请先关闭此开关。

“隐藏 Windows 桌面图标”只调整 Explorer 的图标显示标志，不删除、移动或重新排列桌面文件，也不隐藏任务栏。关闭软件不会自动恢复；可关闭此开关，或用 Windows 桌面右键 → 查看 → 显示桌面图标恢复。

两个开关先读取系统实际状态，点击并确认后才修改。旧本地偏好不会在启动时自动套用；读取失败、系统状态变化或模拟模式下不会直接写入设置。图标接口暂不可用不影响登录启动项单独设置。

## 新闻、市场与农业

设置 → 数据来源可开关免费来源。免费数据由电脑直接读取，不经过作者服务器。页面保留来源日期和单位，失败时显示错误或旧数据标记；不同网络不保证全部来源可达。

市场中心 → 管理自选 → 选择市场、输入代码、点击添加。名称可留空。

| 类型 | 输入示例 | 说明 |
| --- | --- | --- |
| A股 | `600519`、`000001.SZ` | 六位股票代码或明确的交易所后缀 |
| 美股 | `AAPL`、`BRK.B.US` | 来源支持的美股代码 |
| 港股 | `00700`、`700` | 保存为五位代码加 `.HK` |
| 国内期货 | `AG2612.SHF`、`C2701.DCE` | 必须是受支持的明确月份合约，示例不是推荐合约 |
| 海外期货 | `GC=F`、`ZS=F` | 受支持的来源序列；可能换月，不推测主力 |

股票显示来源币种/股。期货保留各自原始计价单位；不同市场时间与推定交易日不会混为一谈。代码被接受不保证该来源始终提供报价。

## AI 客户端额度

设置 → AI 连接中允许读取本机账号与用量后，支持的客户端会自动更新额度，也可手动刷新。运行状态识别不等于已支持额度读取。

豆包使用桌面客户端当前账号，不需要在 GleamDesk 再次网页登录。首次连接时保存并彻底退出豆包（关闭窗口可能仍留在托盘），再刷新一次，以导入 Windows 本机加密的登录缓存；之后可保持豆包运行。缓存最长有效 7 天，登录失效或切换配置档后需重新读取。卡片保留官方返回的订阅窗口和活动赠送额度，不把未返回的数据填成零。

## Agent Room

未配置模型时可以查看房间和成员界面，不能把“未接入”当作已连接。模型凭据、费用确认和本机 Ollama 需要用户自行设置。软件不会因为打开页面而替你购买服务。

## 可选服务器连接

没有服务器也能使用免费新闻、市场和农业来源。需要监控时，再配置自己的 Beszel 或其他可选服务，详见 [VPS 服务](vps-services.md)。

本机 Beszel Hub 随软件启动默认关闭。开启前须已有 `beszel.exe` 和包含原 `data.db` 的数据目录。仅支持 `http://127.0.0.1:端口`；退出 GleamDesk 后 Hub 继续运行。它不会替你安装 Beszel 或修改 Windows 开机启动。

## 排错

- **数据为空或旧数据**：先看来源状态、来源日期和网络，再检查来源开关。不要把读取时间当成行情日期。
- **Beszel 连接被拒绝**：先检查本机 Hub 是否运行；不能仅据此判断 VPS 离线。
- **浏览器预览不显示硬件/服务**：这些功能需要 Windows 桌面版。
- **关闭工作台后 Dock 还在**：这是预期行为；从 HUD 退出程序。

提交问题前请阅读 [隐私说明](PRIVACY.md)，遮挡账户、地址、令牌和聊天内容。
# 邮箱提醒

在工作台设置的“邮箱提醒”中添加账户。QQ、163 需要先在邮箱网页开启 IMAP，并输入客户端授权码；Gmail、Outlook 使用自己的 OAuth 应用配置，点击网页登录并授予只读权限。支持多个账户，分别暂停或移除。

普通新邮件在 HUD 下方显示发件人和标题；验证码邮件突出显示验证码，点击可复制。自动提醒默认显示 30 秒，悬停时保持；正在操作其他 HUD 面板时排队，验证码优先。点击本机 PC 旁边的邮箱图标，可以查看已连接账户、连接状态及最近 20 封收件箱邮件的发件人、主题和时间；可按账户切换或手动刷新。首次加载的旧邮件只列入列表，不弹通知。邮件列表保存在本次运行的内存中，重启后重新只读加载；有效验证码最多保留 5 分钟，手动打开的列表不自动收起，点击关闭、切换面板或点击外部后关闭。复制验证码后，手动列表保持打开；过期验证码不再提供复制。

QQ、163 优先使用 IMAP IDLE，没有该功能时每 30 秒检查；Gmail、Outlook 每 30 秒查询官方只读接口。仅追赶最近邮件，不扫描整个邮箱；每个账户列表最多 20 封；旧邮件只读邮件头，近 5 分钟邮件为识别验证码按需读取正文。IMAP 单封正文最大 192 KiB，超过上限时只根据邮件头提醒，不下载大附件。网络断开后自动退避重连，暂停、移除和模拟模式会停止后续读取。

授权保存在 Windows 凭据管理器，应用目录中的 `mail-otp.json` 只保存账户、开关和查收位置。邮件正文、邮件提醒列表与验证码不落盘，不调用模型或付费翻译服务。移除账户会清除该功能保存的授权。
