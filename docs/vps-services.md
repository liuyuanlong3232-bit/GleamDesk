# 可选 VPS 服务

开发版新增三类独立、只读连接，不依赖作者 VPS。Beszel 的 CPU、内存、磁盘等读取保持原样；没有添加的服务不再制造三个“未知”占位。

## 使用方式

设置 → VPS 连接 → 可选服务：添加所需类型，填写地址或已有 SSH 别名，保存连接，再按需保存令牌。启用后到 VPS 页面点击“读取状态”。默认关闭、手动读取；“页面显示时每分钟读取”须单独勾选。

- 3x-ui：支持已选上游 API Token 版本的 `GET /panel/api/server/status`，参考项目要求面板 ≥3.1.0；实际面板版本尚未联网验收，旧版不自动登录或升级。地址填写面板根地址及自定义前缀，不追加 `/panel` 或 API 路径。显示 Xray 状态/版本及 `netIO.up/down` 的服务器累计网络流量；它不是单个用户、Xray 账户流量、配额或网速。
- sing-box：使用用户已经启用的 Clash API。先读取 `/version` 并确认 `sing-box ` 标识，再读取一次 HTTP `/connections` 快照；不建立常驻 WebSocket，不测试节点延迟、不切换节点。仅显示版本、当前连接数、累计上传/下载；连接目的地址和用户明细不返回前端、不写历史或日志。
- Tailscale（VPS）：复用 Windows OpenSSH 已配置的别名，固定执行 `tailscale status --json`，只取远端 `BackendState`、`Self.Online` 和版本。不用本机状态或其他 Peer 在线冒充 VPS 在线。不安装 SSH/Tailscale，不接受自定义远端命令，不自动接受新主机密钥、不提示输入密码。首次连接与主机身份核对由用户在自己的 SSH 环境完成。

## 连接与保护

### 可选的本机 Beszel Hub 随软件启动

设置 → VPS 连接 → 本机 Hub 随软件启动。默认关闭；填写已安装的 `beszel.exe` 和包含原 `data.db` 的数据目录后保存，主屏会立即检查，后续启动 AgentRoom 时再次检查。路径由用户指定，不依赖作者机器目录，不下载或安装 Beszel。

仅接受 `http://127.0.0.1:端口`，端口至少 1024，不支持反向代理前缀。已有端口健康时复用；被其他服务占用或健康检查失败时不重复启动。只有确认连接被拒绝、程序及原数据库存在时，才以固定 `serve --http 127.0.0.1:端口 --dir 原目录` 参数在后台启动；失败停止本次新进程，不循环重启。模拟模式和远程网页不能触发启动。

关闭此开关不停止正在运行的 Hub，退出 AgentRoom 后 Hub 也继续运行；没有改 Windows 开机启动、VPS、凭据或网络设置。结果显示在该设置区域，并记录到本机应用日志。自动化和隔离页面检查不等于真实启动验收；首次启用会恢复采集并更新原监控数据库，应由用户确认后验收。

- 配置独立保存在应用数据目录 `vps-services.json`，默认空列表；保存前检查原文件，备份为 `vps-services.previous.json`，复用现有原子保存能力。损坏配置不会被默认配置覆盖。
- 两种 HTTP 服务允许 HTTPS；明文 HTTP 仅允许本机回环地址，可用于用户已有的本机转发。不会放宽证书检查，不会开放端口或调整代理、系统设置。
- 令牌复用 Windows Credential Manager 能力，使用独立的服务类型和完整地址作用域。连接 JSON 不含令牌；地址变更后旧令牌不会发给新地址。RPC 同时核对界面上的预期地址，避免另一窗口改地址后保存/删除到错误的令牌槽。
- 关闭连接保留令牌；移除连接时删除当前已保存地址对应的令牌。更换地址前可先删除旧地址令牌；旧地址历史凭据不会自动迁移到新地址。
- 只在本地工作台页面允许配置、凭据管理和读取，远程网页不能调用这些入口。读取经过前端模拟保护和后端进程闸门，模拟切换、配置或凭据变化后丢弃在途旧结果。
- 原生每类来源独立缓存，成功/失败均至少间隔 60 秒；无立即重试。HTTP 禁用跳转、自动 Windows 认证和 Cookie，响应最多 256 KiB。SSH 单次最多 12 秒和 256 KiB，固定只读命令，隐藏子进程窗口。
- 只有显式勾选的来源自动轮询。离开 VPS 页面、卡片不可见或窗口隐藏时停止自动读取；未配置不读取。单个服务失败不影响其他服务，不将认证/连接错误直接判成软件未安装或 VPS 离线。
- UI 展示本次真实检查时刻，缓存不会被标上新时间。失败可保留同一地址上次结果并显示“无法检查”；超过两分钟显示“数据未更新”。各服务地址单列，不把不同地址的状态并入 Beszel 服务器结论。

## 上游与当前验证边界

### 3x-ui 只读详情

VPS 服务卡片增加“查看详情”，在工作台内打开独立详情弹窗，包含入站、用户、节点三个页签。可搜索、按节点和入站筛选，从节点下钻入站、从入站下钻用户；用户每页最多 50 条，搜索覆盖全部已读取条目。

- 固定读取 `GET /panel/api/inbounds/list/slim` 和 `GET /panel/api/nodes/list`，不调用新增、删除、重置流量、启停服务或配置修改接口。精简接口省略用户 UUID、密码和订阅密钥；不支持该接口时不会自动改读完整敏感列表。旧版本或权限不足会分别显示不可用，原管理面板仍可由用户打开。
- 入站显示名称、所属节点、协议/端口、启用/到期/额度状态、累计上传下载、额度、到期信息和用户入口。节点 ID 为来源明确的 null 时显示本机，缺字段显示来源未提供；不按名称猜节点归属。
- 用户仅展示来源提供的名称、使用状态、流量、额度、到期和最近在线记录。启用不代表在线，不额外调用在线探测接口。同名用户在多个入站中保留关联条目，不合并为去重人数，也不相加当成总流量。
- 缺失数值和配置保持未提供；来源明确的额度 0 才显示不限，到期 0 才显示不限期，负到期值显示待首次使用。到期和最近在线字段按来源毫秒读取，节点心跳按来源秒转换，不以本机读取时间替代来源时间。
- 节点显示面板记录的名称、地址、启用与连接状态、入站/用户计数、心跳和版本。心跳超过五分钟提示较旧；空远程节点列表不表示本机没有入站或服务器离线。不会访问节点地址或发起延迟探测。
- 两部分独立失败，不能把无权限或格式错误当成空列表。重复 ID、重复用户标识、流量归属冲突按不可用处理。单次响应继续上限 256 KiB，最多 200 个入站、200 个节点、2000 个用户条目；超出不静默截断。
- 详情默认在用户点击时读取，刷新复用一分钟原生缓存，不制造新读取时间。读取失败可保留同一地址旧详情和原时间；超过两分钟标未更新。模拟开启、配置变化或关闭详情后，旧结果不能再覆盖页面。
- “打开原管理面板”把已配置根地址的 `/panel/` 页面交给现有临时网页工作区，不写网站配置、不携带 API 令牌、不自动登录。原面板按用户登录账户的权限操作，里面的操作不属于本软件的只读 API。首次渲染直接选择目标面板，避免先加载上次恢复的其他网站。

接口依据：[官方入站与精简列表](https://docs.sanaei.dev/docs/reference/api/inbounds/)、[官方远程节点列表](https://docs.sanaei.dev/docs/reference/api/nodes/)。本批只核对公开协议和合成响应，具体服务版本、真实权限和原面板实际登录仍需单独验收。

移植的来源、版本与 MIT 许可证保存在 [licenses/vps-services](../licenses/vps-services/README.md)。只复用需要的读取和字段处理，不捆绑额外采集器、Prometheus、Grafana 或代理软件，没有增加依赖。

本批只做本机编译、合成响应测试及隔离界面验证。没有使用真实 API 令牌、运行真实 SSH、连接/修改 VPS，未替换固定入口或启动新预览。三类真实服务、具体版本和 Windows 原生界面仍需单独授权验收，不能把模拟通过视为已经真实接通。
