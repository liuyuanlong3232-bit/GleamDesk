# 免费数据与可选连接

免费数据由用户电脑直接读取，不依赖作者 VPS。新安装的 SSH、Beszel、可选 VPS 服务和自动付费生成关闭；个人名字和市场自选为空。数据来源可在设置中开关。

新闻使用公开 RSS；市场提供金银参考价、ECB 汇率、腾讯股票公开快照、支持的国内月份期货和海外参考序列。农业来源包括 Open-Meteo、NOAA、CFTC、USDA、世界银行、IBGE、CONAB 与阿根廷官方公开资料。FRED 是独立可选月价来源。

A股输入六位代码或交易所后缀；美股如 AAPL；港股如 00700；期货须使用支持的明确月份代码或海外代码。各市场币种、来源时刻和交易日口径分别显示，不推测主力或缺失价格。

公开网页端点可能延迟、限流、变更或在部分网络不可达。失败保留原日期并标记；没有代理时不保证全部海外来源可访问。软件不自动更改代理，也不通过作者服务器中转。代码许可证不授予第三方数据、商标或图片权利。

自定义 HTTP 接口由用户配置公开 GET 地址和 JSON 字段对应关系；可选连接由用户自行安装所需服务并保管凭据。
