# Screenshot provenance

The refreshed JPG images capture the actual React components from the 0.1.1 candidate using an isolated browser origin/profile with no access to the author's native desktop app data.

- `overview.jpg`: white theme, built-in Developer Simulation; balances are synthetic and labeled.
- `agent-room.jpg`: empty Agent Room, no connected models, no messages or inference calls.
- `settings.jpg`: appearance settings, no configured credentials or server addresses.
- `hud.jpg`: the actual `App` main-screen HUD and its expanded quota details, using the built-in developer simulation in the burgundy theme. The crop contains synthetic quota values, not a connected account.
- `dock.jpg`: two instances of the actual `DockWindow` component, captured at collapsed and expanded sizes inside a presentation page. The native position request is mocked; all other native operations are rejected. The avatar is the creator-authorized brand logo; launcher entries are public defaults. Captions and a neutral gradient backdrop are part of the capture page, not software controls.

External data requests were blocked during capture; only local assets were loaded. The images verify interface presentation only; they are not evidence of live provider connectivity, installed launcher applications, window transparency, screen-edge placement or other native Windows behavior. The creator-authorized brand avatar is deliberately included; private avatar uploads, watchlists, accounts and chats are excluded. Capture date: 2026-10-26 (0.1.1 candidate).


Legacy .png previews are retained from the 0.1.0 source tree; current README links use the refreshed .jpg candidate captures with the authorized brand logo.
