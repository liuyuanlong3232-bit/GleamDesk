# 主屏 HUD 图标

chatgpt.png、claude.png、antigravity.png 取自 Agent HUD 的 Resources，核对日期 2026-10-14：
https://github.com/jazzenchen/agent-hud-open/tree/main/Sources/AgentHUDDesktop/Resources

这些图标随原项目附带 LobeIcons 的 MIT 许可，完整声明保留在 LobeIcons-LICENSE.txt。本项目没有复制 Swift 动画源码；Windows 交互由现有 React/CSS 实现。VPS 和本机头像使用内联 SVG；Room 的动漫头像保持原样。

doubao.svg、gemini.svg 补自同一图标库：https://github.com/lobehub/lobe-icons/tree/master/packages/static-svg/icons 。核对日期同上，适用同一 MIT 许可。主屏按当前运行识别显示，预留且未接入的成员不会冒充已连接。

2026-10-15 补充：Cursor、Copilot、OpenCode、Kimi、Pi、Hermes、OpenClaw、CodeBuddy、WorkBuddy、Qwen、Qoder、ZCode、DeepSeek 原始 PNG 来自上述 Agent HUD Resources；Windsurf、Trae、Goose、Ollama SVG 来自 LobeIcons。继续保留同一 MIT 许可。深色专用变体用于 OpenCode 和 Qoder；单色标志用 CSS 白色蒙版，不修改原图。主屏现按运行识别显示，与是否已安装或保存登录分别处理。
